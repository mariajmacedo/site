Como os computadores funcionam

Versões dos sistemas operacionais

Uma visão geral das versões importantes do Windows, macOS e Linux, e de como cada sistema evoluiu.

Microsoft Windows

Windows é a família de sistemas operacionais da Microsoft. Ele oferece uma interface para usar programas e arquivos, além de gerenciar o hardware do computador. Suas versões trouxeram mudanças na aparência, na segurança e na compatibilidade com dispositivos e aplicativos.

Versões marcantes

  • Windows 1.0 (1985): primeira versão comercial com interface gráfica da família Windows, executada sobre o MS-DOS.
  • Windows 95 (1995): popularizou o menu Iniciar e a barra de tarefas, facilitando o uso do computador.
  • Windows XP (2001): uniu linhas domésticas e profissionais em uma versão conhecida pela interface e ampla compatibilidade.
  • Windows 7 (2009): aprimorou a interface e o desempenho após o Windows Vista.
  • Windows 10 (2015): adotou atualizações contínuas e reuniu recursos para computadores e dispositivos híbridos.
  • Windows 11 (2021; versões 24H2, 25H2 e 26H2): renovou a interface e os requisitos de hardware; a versão 26H2 foi disponibilizada em 2026.

macOS

macOS é o sistema operacional dos computadores Mac, desenvolvido pela Apple. Ele administra o hardware e os aplicativos do Mac e integra recursos com outros produtos da empresa. O sistema já foi chamado Mac OS X e OS X antes de receber o nome macOS.

Versões marcantes

  • Mac OS X 10.0 Cheetah (2001): inaugurou a geração moderna do sistema, com a interface Aqua e uma base técnica Unix.
  • Mac OS X 10.4 Tiger (2005): introduziu recursos como Spotlight para busca e Dashboard para pequenos aplicativos.
  • Mac OS X 10.6 Snow Leopard (2009): priorizou melhorias de desempenho, estabilidade e eficiência.
  • OS X 10.10 Yosemite (2014): trouxe uma interface renovada e maior integração com iPhone e iPad.
  • macOS 10.15 Catalina (2019): encerrou o suporte a aplicativos de 32 bits e separou o iTunes em aplicativos próprios.
  • macOS 11 Big Sur (2020): marcou a mudança para a numeração 11 e redesenhou a interface.
  • macOS 12 Monterey (2021), 13 Ventura (2022) e 14 Sonoma (2023): adicionaram recursos de continuidade, produtividade e personalização.
  • macOS 15 Sequoia (2024): ampliou os recursos de organização de janelas e integração com iPhone.
  • macOS 26 Tahoe (2025) e macOS 27 Golden Gate (2026): continuam a evolução do sistema; Golden Gate é a versão 27 listada pela Apple.

Linux

Linux é o núcleo (kernel) de código aberto que faz a comunicação entre os programas e o hardware. Ele não corresponde a uma única versão de sistema para computadores pessoais: projetos combinam o núcleo com ferramentas e aplicativos para criar distribuições, como Ubuntu e Debian. O núcleo tem suas próprias versões, publicadas em séries numeradas.

Versões do núcleo Linux

  • Linux 1.0 (1994): primeira versão estável oficial do núcleo, com suporte inicial a computadores pessoais.
  • Série 2.6 (a partir de 2003): ampliou recursos e suporte a diferentes processadores e dispositivos.
  • Séries 3.x, 4.x, 5.x e 6.x: continuaram a evolução do núcleo, com atualizações de hardware, segurança, desempenho e sistemas de arquivos.
  • Série 7.x (2026): série atual do núcleo; o site oficial lista a versão estável 7.2.10 em outubro de 2026.

Exemplos de distribuições Linux

  • Ubuntu 26.04 LTS: distribuição voltada a computadores pessoais e servidores; versões LTS recebem um período maior de suporte padrão.
  • Debian 13 “Trixie”: distribuição comunitária cuja versão estável atual é a 13, com atualizações de manutenção.
